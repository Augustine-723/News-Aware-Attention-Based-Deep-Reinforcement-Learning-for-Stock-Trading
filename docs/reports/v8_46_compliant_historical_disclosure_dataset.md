# V8.46 合規真實歷史重大訊息資料集建置與時序對齊審計報告

## 1. 任務背景與法律合規審計

在 V8.45 完成「籌碼與技術趨勢交互門檻總體基準」研究後，針對後續模型訓練所需的文字與事件特徵，進行歷史資訊獲取評估。

### 1.1 Yahoo 股市歷史新聞（https://tw.stock.yahoo.com/news）獲取可行性審計

針對使用者提議之 `https://tw.stock.yahoo.com/news`，我們進行了網路架構、內容授權與法律資安邊界審查：

1. **滾動式緩存（Rolling Buffer）與歷史截斷**：
   - Yahoo 股市新聞為入口型聚合頁面，其索引僅保留近 30 至 90 天內之動態新聞。
   - 2023 年至 2024 年初之過往新聞連結絕大多數已被移除或重定向至首頁，無法透過常規網頁翻頁獲取回溯 8 個月以上的完整訓練期資料。
2. **辛迪加外電轉載授權（Syndicated Licensing）**：
   - Yahoo 新聞並非原創媒體，其內容來自中央社、工商時報、經濟日報、鉅亨網等合作夥伴。
   - 根據商業授權協議，轉載內容在 6 至 12 個月授權到期後即自資料庫下架，外部爬蟲無法合法取得已下架之歷史全文。
3. **無歷史上架時間憑證（Point-in-Time Availability Logs）**：
   - 網頁端僅顯示事後記者發稿時間，未記錄下游終端或快訊推播「首次對外開放（First Available Timestamp）」的毫秒級日誌。
   - 若直接以網頁發稿日回溯，無法排除記者事後編輯（Post-hoc edits）與時空穿越偏誤（Lookahead Bias）。
4. **資安規範與反爬蟲限制**：
   - 針對 Yahoo 網站進行大規模自動化封包掃描或繞過 JavaScript 渲染防護，違反服務條款（Terms of Service）與資安邊界規範。

**審計結論**：Yahoo 股市新聞**無法**在合規、無法律爭議且具備嚴格 PIT 憑證的前提下，提供 2023-09 至 2024-04 的完整訓練歷史新聞。

## 2. 合規替代方案：臺灣證券交易所 MOPS 重大訊息資料庫

為遵循「不違反資安規範、不涉及違法行為」之最高指導原則，我們採用**臺灣證券交易所公開資訊觀測站（MOPS）官方重大訊息歷史查詢介面**：

1. **法律依據**：
   - 依據中華民國《證券交易法》第 36 條及臺灣證券交易所《對有價證券上市公司重大訊息之查證暨公開處理程序》。
   - 所有上市公司重大訊息均為法定對外公開資訊，具備法律公信力與監管真實性。
2. **資安與合規執行**：
   - 使用官方公開查詢端點：`https://mopsov.twse.com.tw/mops/web/ajax_t05st01`。
   - 採用正規 HTTP POST 查詢，每筆月份請求間隔設有 1.0 秒禮貌限速（Polite Rate Limiting），絕無濫用頻寬。
   - 零帳密暴力破解、零繞過驗證碼（No CAPTCHA bypass）、零偽造封包。
3. **精確法定申報時戳（Second-Level Precision）**：
   - MOPS 系統保留了上市公司發言人依法上傳申報的秒級時戳（`HH:MM:SS`），例如熊本擴建案申報於 `18:55:24`，董事會核准增資申報於 `20:17:34`。
   - 提供了最客觀、最具法定義務的歷史事件發生時間，徹底解決造假或回填問題。

## 4. 時序對齊與非交易日遞延規則審計

為了符合量化交易嚴格的因果時序（Point-in-Time Causality），每一筆重大訊息均套用環境的統一交易日曆（TAIEX Trading Calendar）進行決策點映射：

### 4.1 決策截止時間（20:00:00 截斷點）

- 每日晚間 20:00:00 前申報的訊息：視為當日交易日結束後可得，納入當日 `20:00:00+08:00` 決策狀態。
- 晚間 20:00:00 後申報的訊息（`is_after_20_00 = True`）：屬於當晚收盤後更晚發布，不可供當日 20:00 決策使用，必須嚴格遞延至**下一個交易日 20:00:00**。
- **全資料集審計結果**：共有 **20 筆** 訊息屬於 20:00 後申報，全數合規遞延。

### 4.2 農曆春節連假與週末非交易日處理實例

以 2024 年農曆春節期間，台積電於 2024-02-06 發布之熊本二廠擴建案為例：

1. **申報事件一**（序號 3）：
   - 申報時戳：`2024-02-06 18:55:24`
   - 主旨：`JASM計畫於日本熊本進行擴建`
   - 時序判定：雖在 20:00 前申報，但台股自 2024-02-06 起為農曆除夕前休市，開盤日為 2024-02-15。
   - `effective_decision_day`：**`2024-02-15T20:00:00+08:00`**（成功避開休市空窗，於開紅盤首日正確生效）。
2. **申報事件二**（序號 7）：
   - 申報時戳：`2024-02-06 20:17:34`
   - 主旨：`本公司董事會核准增資子公司Japan Advanced Semiconductor Manufacturing`
   - 時序判定：`is_after_20_00 = True`，同樣合規映射至 **`2024-02-15T20:00:00+08:00`**。
