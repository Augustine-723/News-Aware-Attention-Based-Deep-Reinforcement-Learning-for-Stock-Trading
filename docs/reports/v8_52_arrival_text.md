# 新公告的主旨會讓凍結策略改變動作嗎？

2024 年 2–3 月，台積電、長榮與富邦金共 43 個股票日在決策前出現新公告。三個凍結的 C 組模型共產生 129 次配對。只替換新公告主旨，129 次皆改變持股與現金的 Q 值差，動作翻轉 0 次。

V8.48 曾同時替換所有可見主旨；V8.50 在 B 組測試新增公告的出現及年齡。本次以台北時間前一交易日 20:00 至本交易日 20:00（左開右閉）界定新增公告，逐股逐日核對清冊筆數，只把這些槽位的文字向量替換為固定句子「本公司公告重大訊息。」的向量。舊主旨、公告數量、年齡、市場輸入與當下部位皆保留。策略沿真實分支推進，各配對共用該時刻的帳戶部位。

| 指標 | 觀察值 |
|---|---:|
| 可執行交易決策日 | 33 |
| 全部股票 × 種子 × 日期配對 | 297 |
| 有新公告的配對 | 129 |
| 無新公告的對照配對 | 168，Q 值差全部相同 |
| 有新公告時 Q 值差的絕對變化，中位數／最大值 | 0.000294／0.002461 |
| 有新公告時，替換主旨使 Q 值差距零點縮短的最大比例 | 3.35% |

最大變動發生在 3 月 13 日富邦金（種子 100），當次有 10 筆新公告。原先 Q(Long) − Q(Cash) 為 −0.073547，替換後為 −0.071086，兩者均選擇現金。三組權重雜湊與全部 297 筆真實分支的日期、動作及 Q 值差均通過 V8.48 逐筆核對。

此結果衡量固定模型對公告主旨的敏感度。比較沿用申報時間估計可得性，三個種子共用市場觀測。此次使用已研究過的二至三月測試窗，獨立前瞻效度仍待新期間驗證。
