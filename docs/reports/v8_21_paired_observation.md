# V8.21 成對觀測整合驗證

使用 2330 的既有市場快取建立三個決策日的成對觀測。兩份觀測呼叫同一個 HistoricalSnapshotBuilder 實作，共用行情、交易日曆、輔助資料及持倉預設。空事件組傳入空清單，另一組僅傳入隔離的合成測試事件。兩組都走既有張量驗證。

```bash
python -m stock_rl.evaluation.paired_observation > paired_observation.json
python -m pytest -q tests/test_paired_observation.py
```
