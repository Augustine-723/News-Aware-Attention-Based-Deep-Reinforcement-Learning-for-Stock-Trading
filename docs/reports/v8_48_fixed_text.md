# 固定模型後，公告主旨會改變持股決策嗎？

三個依 V8.47 C 組流程重建的模型，在 468 次配對中，替換主旨都改變了持股與現金的 Q 值差，但沒有一次改變最終動作。範圍限於台積電、長榮與富邦金，按申報時間估計公告可得性。

| 評估期間 | 可執行決策日 | 股票 × 種子的配對數 | Q 值差改變 | 動作翻轉 | Q 值差的絕對變化（中位數／最大值） |
|---|---:|---:|---:|---:|---:|
| 2024 年 2–3 月 | 33 | 297 | 297 | 0 | 0.000388／0.004380 |
| 2024 年 4 月 | 19 | 171 | 171 | 0 | 0.000225／0.005504 |

## 比較方式

沿用 V8.47 的法人買賣超基準、404 筆公告、304 個不同主旨、訓練期正規化與驗證選模。每個種子各訓練一次 C 組，接著固定權重。對每一個可執行決策日，複製實際觀測，只將文字向量替換為固定句子「本公司公告重大訊息。」的 BGE 向量。兩次推論共用市場特徵、事件槽、時間、metadata 與當前部位；環境只執行真實主旨分支的動作。Q 值差定義為 Q(Long) 減 Q(Cash)，單位為模型輸出。最末日沒有期內下一交易日開盤，故不計入決策。

所有配對都至少有一個可見事件槽。種子 100 在兩期均選現金；種子 42 與 2024 在 2–3 月各有 49、34 次持股決策，四月各有 23、19 次。結果涵蓋兩種動作。各種子使用同一組行情，468 次配對不能視為 468 個獨立交易日。

## 與歷史模型的關係

V8.47 的公開程式保存推論結果，未匯出 C 組權重。此次重新訓練後，真實主旨分支與 V8.47 歷史紀錄在 2–3 月有 59／297 次動作不同，在四月有 29／171 次不同。符合全部日期、動作與淨報酬的股票×種子組合分別為 4／9 與 5／9。權重差異的原因尚未確定。本次估計的是這三個重建模型的輸入敏感度，V8.47 的 C、D 分別重訓比較仍是另一個問題。

## 重現

在可用已驗證 BGE 快取的環境，從專案根目錄執行。四月的 22 份市場回應會依 V8.40 清冊驗證。此次使用 Python 3.12.14、PyTorch 2.5.1 CPU、NumPy 2.5.5、pandas 2.2.3、Transformers 4.44.2。

```bash
python -m stock_rl.evaluation.mops_fixed_text --april-cache april_source_cache \
  --checkpoints checkpoints/v8_48 --output fixed_text.json
```

[逐筆 Q 值差、動作、權重雜湊與 V8.47 重現標記](../results/v8_48_fixed_text.json)。如能取得原始三個 C 組 checkpoint，可在同一批觀測上直接比對兩代權重。
