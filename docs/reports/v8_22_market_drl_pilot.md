# V8.22 真實行情 Market-Only DRL 小型實驗

本實驗建立 M0 的第一列樣本外結果。行情使用專案快取的 2330、2603、2881，沿用現有資料可用時間估計、20:00 台北決策與下一交易日開盤模擬。事件槽全空。三股共用一套模型參數，各自從現金開局並獨立執行 Long／Cash。

## 重現

```bash
python -m stock_rl.evaluation.market_drl_pilot --checkpoints checkpoints/v8_22 > market_drl_pilot.json
python -m pytest -q tests/test_market_drl_pilot.py tests/test_market_baseline.py tests/test_env_execution.py tests/test_paired_observation.py
```

- [實驗配置](../../configs/v8_22_study.json)記錄三個種子、時序切割、訓練預算、模型選擇與待取得新聞的 M1–M4 設計。
- [實驗結果](../results/v8_22_market_drl_pilot.json)記錄行情檔 SHA-256、分割與正規化資料雜湊、執行環境、驗證紀錄，以及逐股逐日動作、權益、交易次數與成本。
- 每個種子的 checkpoint 保存模型、正規化統計、配置與來源雜湊。重跑可在本機重建，權重檔依專案規則存放於忽略目錄。

## 切割與訓練

| 區間 | 起迄日期 | 每股交易日 | 每股可執行轉移 |
|---|---|---:|---:|
| 訓練 | 2023-09-01 至 2023-12-29 | 83 | 82 |
| 驗證 | 2024-01-02 至 2024-01-31 | 22 | 21 |
| 測試 | 2024-02-01 至 2024-03-29 | 34 | 33 |

訓練資料的 60 日行情視窗可讀取更早的歷史資料。三段各自建立環境，決策與下一交易日的獎勵均落在該段內。正規化器只擬合訓練觀測，驗證與測試使用同一組凍結統計。使用既有完整多模態骨幹和 Double DQN agent，由 RL 損失端到端訓練兩輪。這是小型 M0 實驗，原三階段訓練示範另見 V8.20。每個種子僅依驗證期間平均成本後報酬選 epoch，同分保留較早 epoch。測試時採貪婪策略，未更新模型。
